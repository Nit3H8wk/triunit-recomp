# Security and rights notices

## Supported version

Only the `main` branch is supported. Fixes are made there.

## Reporting a vulnerability

Report it privately through GitHub's private vulnerability reporting on this
repository (Security tab, "Report a vulnerability"), which opens a private
security advisory. Do not open a public issue for a vulnerability.

## Takedown and rights notices

To report material that you believe infringes your copyright, trademark or
other rights, use the same private channel (a private security advisory on
this repository). Please identify the file paths or commits concerned and the
right you hold.

## Response

A reported item is removed from `main` the same day it is received, while it is
reviewed. The outcome of the review is given in the advisory.
